Flutter Clean Architecture Instagram Clone

A fully functional Instagram clone built with Flutter and Firebase, following Clean Architecture principles.
Supports both frontend and backend with nearly all functionalities.

🔑 Notes

Firebase, Messaging, Agora keys, and google-services.json are NOT included — follow the setup guide below.

Currently improving codebase and web support.

🌟 Features
🌍 General

Multi-language: Arabic & English

Theme: Dark & Light


📸 Posts

Upload images, videos, or both in a single post

Multi-image/video support

Like, comment, reply, edit, delete, and share posts

View likes, profiles of likers

Unfollow from post screen

📰 Timeline

Custom feed from followers

Refresh & pagination (5 by 5)

View all posts or switch to grid/timeline view

🔍 Search

Search users by username

📹 Videos

Video posts with sound & play control

Video-only screen with post actions

👤 Profile

Follow/unfollow

Edit profile

Separate views for videos & images

Grid or timeline layout switch

💬 Chat

One-on-one & group messaging

Support for:

Text

Images (camera & gallery)

Voice

Video calls (1-to-1 & group)

🔔 Push Notifications

In-app notifications for likes, comments, follows

Send posts to chat

💻 Web Version Snapshots
